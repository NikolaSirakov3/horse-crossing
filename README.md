# Horse Crossing

A stone-hopping river crossing game, built on plain HTML5 canvas 2D — no engine,
no framework, no dependencies.

**Play it: https://nikolasirakov3.github.io/horse-crossing/**

Press **GO** to send the horse to the next rock. Every stone survived raises the
multiplier; **COLLECT** banks the winnings before he slips. Clear the river and
he lands on the far bank.

`index.html` is a single self-contained build — all code and artwork inlined,
nothing fetched at runtime. It opens straight off disk too.
